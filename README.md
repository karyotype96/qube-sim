# Qube - a Rust library for quantum computer simulation (currently _very_ WIP)

I must confess, I am no expert in quantum computing. That's why this project is likely to be a perpetual "work in progress" as I learn more and more about the subject, and it is very much subject to change at any point in time. That said, the aim of this project is to allow for simulation of quantum circuits using Rust syntax. If I had the option to adapt something like this to write programs for actual quantum computers, I would, but I'm afraid I'm too broke to afford one of those.
